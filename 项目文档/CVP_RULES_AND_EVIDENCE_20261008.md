# CVP 当前规则核对（2026-10-08 JST）

官方主文已更新为 2026 年 10 月的三层级方案，覆盖 Opus 5.5、Sonnet 5.5、Mythos 5.1 等。个人目前只能以付费计划申请 **Defense Access**；组织统一提交一份申请。所列材料是身份/组织信息、安全工作描述和适用安全控制声明，未列固定 30 项目、逐项目拦截截图或降级日志要求；这不保证申请获批。[官方项目说明](https://support.claude.com/en/articles/14604842-cyber-verification-program)

个人须经 Google 或等效身份提供者登录，自获授权起启用 MFA；2026-12-15 起要求抗钓鱼 MFA，停用邮件 magic link 和静态长期凭据。Claude.ai/Claude Code 使用 OAuth。截止前至多一个 API key，须安全保存、不共享且至少每 7 天更换。个人授权仅本人使用，流量保留并受监控，不提供 ZDR；还须遵守适用的事件报告、合作与持续复核要求。[个人安全要求第 3 节](https://support.claude.com/en/articles/17202708-cyber-verification-program-security-requirements)

不能把个人条款扩大为“所有组织的 ZDR 一律不能参与”：主文对已有 Fable/Mythos 保留豁免的组织另有过渡安排。[现有成员条款](https://support.claude.com/en/articles/14604842-cyber-verification-program)

本次使用渠道已由申请人说明为 Claude.ai / Claude Code；实际申请身份、付费计划、安全控制和批准状态尚未核实。项目附件按真实贡献、任务授权和具体提交整理。旧 [2026-10-04 规则](CVP_RULES_AND_EVIDENCE_20261004.md)及更早证据保留历史时点；与新版不同处以本页所引当前官方来源为准，实际申请时再核官方页面。
